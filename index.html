How to install

STEP 01

Install Fabric

Use the Minecraft version listed above and install its matching Fabric Loader.

STEP 02

Move the JAR

Place leeclient-1.0.0.jar in your Minecraft mods folder.

STEP 03

Launch the game

Start the Fabric profile. Back up your worlds and check compatibility if the game crashes.
